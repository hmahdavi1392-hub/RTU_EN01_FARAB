RTU-EN01  -  Farab  -  Android app (project)
==============================================

این یک پروژه آماده است. باید یک بار آن را به APK تبدیل کنی (ساخت APK روی گوشی انجام نمی‌شود).

راه ۱: ساخت APK با GitHub (بدون نصب چیزی روی کامپیوتر)
-------------------------------------------------------
1) در github.com یک حساب رایگان بساز و یک Repository جدید بساز (مثلاً rtu-en01).
2) Add file > Upload files را بزن و محتوای همین پوشه را بکش و رها کن
   (فایل‌ها و پوشه‌های داخل پوشه، نه خود فایل zip) و Commit changes را بزن.
3) اگر پوشه مخفی  .github  آپلود نشد:
   Add file > Create new file ، در کادر نام بنویس:
       .github/workflows/build-apk.yml
   و کل متن فایل build-apk.yml.txt را در آن کپی کن و Commit کن.
4) تب Actions > «Build APK» > Run workflow را بزن. حدود ۵ تا ۱۰ دقیقه صبر کن.
5) روی اجرای تمام‌شده (تیک سبز) کلیک کن. پایین صفحه در Artifacts فایل
   RTU-EN01-apk را دانلود کن. داخل zip آن فایل app-debug.apk هست.
6) app-debug.apk را به گوشی بفرست و نصب کن
   (اجازه «نصب از منبع ناشناس / Install unknown apps» را بده).

راه ۲: ساخت با Android Studio
-----------------------------
1) Android Studio را نصب کن، File > Open و همین پوشه را انتخاب کن.
2) صبر کن Gradle Sync تمام شود (بار اول اینترنت می‌خواهد).
3) Build > Build Bundle(s) / APK(s) > Build APK(s)
   فایل: app/build/outputs/apk/debug/app-debug.apk

بعد از نصب
----------
- گوشی باید به همان Wi-Fi وصل باشد که RTU روی آن است (پیش‌فرض 192.168.0.20 پورت 502).
- در تب Settings می‌توانی IP و بقیه تنظیمات را عوض کنی. چند دستگاه هم می‌شود اضافه کرد.
- صفحه هنگام باز بودن برنامه روشن می‌ماند و وقتی برنامه در پس‌زمینه برود، خواندن متوقف می‌شود.
